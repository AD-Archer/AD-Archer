# Contributing to AD-Archer

Thank you for considering contributing to this project! Here are some guidelines to help you get started:

## How to Contribute

1. **Fork the repository** and clone it locally.
2. **Create a new branch** for your feature or bugfix.
3. **Make your changes** and commit them with clear messages.
4. **Push your branch** to your forked repository.
5. **Open a pull request** using the provided template.

## Code Style
- Follow the existing code style and conventions.
- Run `pnpm lint` and `pnpm type-check` before submitting your PR.
- Add comments to complex or non-obvious code.

## Pull Request Guidelines
- Fill out the PR template completely.
- Reference any related issues in your PR description.
- Ensure your changes do not break existing functionality.
- Add tests for new features or bug fixes if possible.

## Reporting Issues
- Use the issue template to report bugs or request features.
- Provide as much detail as possible, including steps to reproduce.

## Code of Conduct
- Please be respectful and considerate in all interactions.
- See [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md) for details.

## Getting Help
- If you have questions, open an issue or contact the maintainer.

Happy coding!
